Synthesized from Fatih Kadir Akın's flagship open-source repositories:
1. **Awesome ChatGPT Prompts (`f/prompts.chat` - 169k+ Stars)**:
   - Over 200+ curated and community-validated expert system personas (Linux Terminal, UX/UI Developer, Senior Architect, Academic Advisor, Financial Analyst, Cybersecurity Red Teamer).
   - Structured persona framing rules: "Act as...", input formatting constraints, zero-preamble directives, and domain-grounded tone calibration.
2. **OpenCase Deterministic Detective Engine (`f/opencase`)**:
   - Data-driven case investigation and clue discovery graph.
   - Deterministic deductive reasoning: Linking suspects, evidence, statements, alibis, and timelines into an unshakeable proof matrix.
   - Forensic hypothesis verification with counterfactual checking.
3. **Jetpack Docs Agent Scaffolding (`f/jetpack-docs`)**:
   - High-speed markdown documentation generator designed for both human readers and AI agents.
   - Structured headings, API references, runnable code playground examples, and semantic navigation trees.
