# S107: MiroFish & BettaFish Swarm Prediction Engine (mirofish-bettafish-swarm-prediction)

## ⚡ Overview & Swarm Architecture
Synthesized from GitHub's premier open-source multi-agent simulation and predictive intelligence ecosystem (>116,000+ stars combined):
1. **MiroFish Swarm Simulation Core (`666ghj/MiroFish` - 72.0k Stars)**:
   - "A Simple and Universal Swarm Intelligence Engine, Predicting Anything."
   - Ingests unstructured documents (policy drafts, product launches, corporate filings, crisis announcements) and spawns hundreds of diverse, persona-conditioned autonomous agents.
   - Multi-round interaction cycles: Agents debate, form opinion clusters, undergo sentiment shifts, and propagate influence across social topology.
   - Predictive trajectory modeling: Forecasts probability distribution of public sentiment, narrative emergence, and potential backlash risks.
2. **BettaFish Public Opinion Assistant (`666ghj/BettaFish` - 42.1k Stars)**:
   - "人人可用的多Agent舆情分析助手，打破信息茧房，还原舆情原貌，预测未来走向，辅助决策！从0实现，不依赖任何框架。"
   - Pure native implementation with zero third-party framework overhead.
   - De-biasing and cocoon breaking: Reconstructs real multi-perspective sentiment graphs across noisy public discourse.
3. **MiroFish-Offline Local Engine (`nikmcfly/MiroFish-Offline` - 2.5k Stars)**:
   - 100% local hardware execution powered by Ollama SLM/LLM inference and Neo4j graph databases.
   - Zero cloud API dependency for privacy-preserving corporate and legal simulations.
4. **MindSpider & Deep Search Agent (`666ghj/MindSpider` & `666ghj/DeepSearchAgent-Demo`)**:
   - High-precision sentiment crawler designed specifically for public discourse scraping.
   - Minimalist multi-step iterative search agent verifying empirical facts before consensus simulation.
