# 🧩 MBTI (MYERS-BRIGGS TYPE INDICATOR) SPECIFICATION
- **4 Polaritas Utama**:
  1. Extraversion (E) vs Introversion (I) — Orientasi energi mental.
  2. Sensing (S) vs Intuition (N) — Cara memproses informasi empiris vs konseptual.
  3. Thinking (T) vs Feeling (F) — Dasar pengambilan keputusan rasional vs nilai empati.
  4. Judging (J) vs Perceiving (P) — Struktur gaya hidup terencana vs fleksibel.
- **16 Tipe Kepribadian**: INTJ, INTP, ENTJ, ENTP, INFJ, INFP, ENFJ, ENFP, ISTJ, ISFJ, ESTJ, ESFJ, ISTP, ISFP, ESTP, ESFP.
