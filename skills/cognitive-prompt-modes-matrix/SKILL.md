# 🧠 Cognitive Prompt Modes Matrix (10 Mental Model Frameworks)

Use this skill when modifying, adjusting, or constraining AI reasoning depth, communication style, dialectical challenge, or problem-solving structure.

## The 10 Cognitive Reasoning Modes

| Mode Modifier | Indonesian Directive | Primary Purpose & Cognitive Function |
|---|---|---|
| **`TL;DR`** | *Ringkas jawaban panjang jadi inti saja.* | High-density distillation of conclusions, eliminating all narrative filler. |
| **`ELI10`** | *Jelaskan topik rumit pakai bahasa simpel.* | Analogy-driven simplification accessible to a 10-year-old without loss of essential truth. |
| **`LAYMAN’S TERMS`** | *Ubah bahasa teknis jadi bahasa awam.* | Demystifies jargon, technical acronyms, and theoretical abstracts for non-experts. |
| **`BREAKDOWN STEPS`** | *Pecah jadi langkah satu per satu.* | Algorithmic, sequential execution roadmap with clear prerequisite milestones. |
| **`PROS & CONS`** | *Kasih plus minus sebelum ambil keputusan.* | Objective multi-dimensional tradeoff audit with weighted positive/negative impacts. |
| **`COMPARE / CONTRAST`**| *Bandingkan dua pilihan dengan jelas.* | Multi-attribute matrix evaluation highlighting key differentiators and fit contexts. |
| **`SOCRATIC METHOD`** | *Bimbing lewat pertanyaan, bukan langsung jawab.* | Guided discovery through targeted inquiry to stimulate critical self-reflection. |
| **`DEVIL’S ADVOCATE`** | *Cari sisi lawan dari ide kamu.* | Dialectical opposition testing assumptions and unearthing counter-arguments. |
| **`PARETO (80/20)`** | *Fokus hal kecil yang hasilnya paling besar.* | Identifies the critical 20% inputs that produce 80% of desired outputs/results. |
| **`REDTEAM`** | *Cari kelemahan ide dan blind spot.* | Adversarial vulnerability scanning to expose failure modes, exploit risks, and blind spots. |

## How to Use
`/omni-auto [TL;DR | ELI10 | PARETO | REDTEAM | DEVILS-ADVOCATE]: [Topic / Prompt]`
