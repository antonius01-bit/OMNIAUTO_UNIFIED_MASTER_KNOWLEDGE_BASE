# 📈 Open-Source BI & Statistical Data Analyst (S152)

## 📌 Overview & Core Architecture
The `open-bi-statistical-data-analyst` Super-Skill replaces expensive enterprise BI and statistical suites (Tableau, Power BI Pro, SPSS, Minitab) with open-source tools:
1. **Metabase & Apache Superset**: Open-source business intelligence, no-code visual query builders, SQL exploratory workbenches, and interactive executive dashboards.
2. **Jamovi & PSPP**: Free, modern statistical analysis suites providing SPSS-equivalent outputs for ANOVA, regression, factor analysis, and non-parametric tests.
3. **GNU Octave & Scilab**: Numerical computation and linear algebra engines providing drop-in compatibility with MATLAB scripts.
4. **Academic Statistical Rigor**: Assumption checking (normality, homoscedasticity, multicollinearity VIF), effect sizes (Cohen's $d$, $\eta^2$), and APA7 reporting.

---

## ⚡ Core Operational Modes & Commands
- `/open-bi dashboard [dataset]`: Creates a structured dashboard specification with KPIs, time-series charts, and funnel graphs.
- `/metabase-dash query [sql]`: Synthesizes visual SQL queries with parameters, filters, and drill-through actions.
- `/jamovi-stats analyze [data]`: Executes classical and Bayesian statistical tests with exact $p$-values and confidence intervals.
- `/academic-statistics report`: Formats statistical outcomes into publication-ready APA7 tables.

---

## 📊 Supported Statistical Methodologies
- **Descriptive & Exploratory**: Skewness, Kurtosis, Shapiro-Wilk, Levene's test.
- **Inferential**: Independent $t$-test, Paired $t$-test, One-way / Two-way ANOVA, MANOVA, ANCOVA.
- **Regression & Modeling**: Multiple Linear Regression, Logistic Regression, Hierarchical Regression, Mediated Moderation.
- **Psychometrics**: Cronbach's Alpha, Exploratory Factor Analysis (EFA), Confirmatory Factor Analysis (CFA).
