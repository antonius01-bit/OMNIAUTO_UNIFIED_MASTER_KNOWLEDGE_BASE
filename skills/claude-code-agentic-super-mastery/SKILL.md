## 🛠️ The 5 Essential MCPs for Claude Code
To empower Claude Code beyond local terminal commands, wire the 5 core Model Context Protocol (MCP) servers:
1. **Perplexity MCP**: Grants real-time web browsing, documentation lookups, and citation retrieval directly from the terminal without manual tab switching.
2. **Puppeteer / Chrome DevTools MCP**: Headless browser automation, DOM inspection, screenshot capture, and web application visual QA.
3. **Filesystem & SQLite MCP**: Sub-millisecond database queries, structured schema migrations, and high-performance local data operations.
4. **GitHub MCP**: Automated PR creation, code review comments, issue triaging, and commit management across remote repositories.
5. **Memory MCP**: Cross-session persistent knowledge graph, tracking architectural decisions, API contracts, and user preferences.

## 📜 Custom SKILL.md Authoring Framework (Satria Bahari Heuristic)
Every Claude Code custom skill must be defined in a dedicated directory with a structured `SKILL.md` containing strict frontmatter:
```yaml
---
name: your-skill-name
description: Clear, actionable description of when Claude should trigger this skill.
---

# Instructions
- Role & Context
- Pre-requisites & Environment Checks
- Step-by-Step Execution Protocols
- Guardrails & Anti-Patterns
```

### Key Execution Modes:
- **Interactive Mode**: Normal CLI pair programming with user confirmation.
- **Headless Mode (`claude -p "..." --dangerously-skip-permissions`)**: Automated background agent execution for scheduled CI/CD pipelines.
- **Subagent Delegation**: Spawning child agents in isolated Git worktrees to prevent unstaged conflict corruption.
