## 🔍 Hover Annotations Syntax (`Obsidian-Hover-Annotations`)

Inline markup format:
```markdown
The system implements [[viking://protocol|OpenViking VFS]]{annotation: "Hierarchical context DB with directory recursive retrieval on port 3111"}.
```
On mouse hover, an interactive glassmorphic card renders the annotation metadata, citations, and source proofs without disrupting visual flow.
