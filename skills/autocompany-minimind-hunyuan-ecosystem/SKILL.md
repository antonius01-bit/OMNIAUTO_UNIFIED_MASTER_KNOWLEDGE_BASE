### The `consensus.md` Memory Protocol
The autonomous company operates in a continuous heartbeat cycle:
1. **Heartbeat Trigger**: Inspects `consensus.md` for uncompleted roadmap items and blockers.
2. **Squad Formation**: Spawns ephemeral task teams (e.g. Architect + Coder + Reviewer).
3. **Execution & CI/CD**: Codes feature, runs test suites, builds production artifacts.
4. **Consensus Update**: Documents progress, commits git changes, and queues next milestone.

## 🎙️ MiniMind-O: On-Device Multimodal Omni SLM

Developed by `jingyaogong`, MiniMind-O democratizes multimodal AI on consumer hardware:
- **Parameter Scale**: $\sim 0.1\text{B}$ parameters. Trainable in $\sim 2\text{ hours}$ on an RTX 3090/4090.
- **Thinker–Talker Dual-Path Architecture**:
  - **Thinker**: Understands text, audio, and image inputs; generates reasoning tokens.
  - **Talker**: Implements Multi-Token Prediction (MTP) to stream audio codec tokens (Mimi codes) directly.
- **Full-Duplex Interactivity**: Supports natural barge-in (interruption) during voice conversation.
- **Phone-Mode WebUI**: Includes responsive WebRTC and WebSocket streaming client.

---

## ⚡ Tencent Hunyuan Hy4 Frontier MoE Specifications

- **Total Parameters**: 770B MoE ($49\text{B}$ active per token).
- **Context Window**: 1,000,000 tokens (1M).
- **Gated DeepSeek Sparse Attention**: High-efficiency KV caching for extended context processing.
- **10B Speculative Decoding Layer (MTP)**: Predicts multiple future tokens concurrently, increasing inference throughput by $2.5\times$.
