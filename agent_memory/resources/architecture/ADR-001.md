## 1. Context & Problem Statement
As autonomous AI agents execute complex long-horizon workflows across software engineering, academic synthesis, multimodal design, and multi-agent coordination, traditional monolithic prompts and flat vector embeddings suffer from:
1. High token consumption and prohibitive API billing.
2. Context window degradation and catastrophic forgetting across turns.
3. Brittle flat vector retrieval lacking ontological structure and spatial boundaries.
4. Single-point-of-failure API dependency (rate limit HTTP 429 and server outages).

---

## 2. Architectural Decisions

### 2.1 Dual-Mirrored 134 Super-Skill Modular Mesh
- **Global Plugin Layer**: C:\Users\antoni\.gemini\config\plugins\dola-ai\skills\ contains all 134 skill folders with standardized SKILL.md definitions.
- **Local Portable Layer**: C:\Users\antoni\Dola\skills\ maintains an exact offline replica, tracked in SKILL_REGISTRY.md and audited in SKILL_LOG.md.
- **Modularity**: Every capability is decoupled into discrete, composable skills (S1–S134) spanning academic research, full-stack development, agent swarms, multimodal production, and enterprise governance.

### 2.2 OpenViking Virtual Filesystem Protocol (iking://)
- Context memory is structured as an inspectable filesystem rather than an opaque vector blob.
- URI schema: iking://[folder]/[subfolder]/[file].
- Top-level directories:
  - iking://user/: User persona, coding standards, style preferences.
  - iking://resources/: Ingested technical documentation, API specs, and ADRs.
  - iking://sessions/: Chronological episodic memory and diff checkpoints.
  - iking://skills/: Distilled procedural routines and surgical refactoring patterns.
- **Directory Recursive Retrieval**: Queries are resolved in two stages (directory routing followed by bounded drill-down search), minimizing token waste and hallucination.

### 2.3 Free-LLM Mesh Failover Cascade (S125)
- All outbound agent requests are processed through a 3-tier zero-cost gateway:
  - **Tier 1 (Speed & Volume)**: Groq (14.4k RPD, sub-second latency) + Google AI Studio (9k RPD, 1M context).
  - **Tier 2 (Context & Capacity)**: Mistral (/mo credit) + Cloudflare Workers AI (10k neurons/day).
  - **Tier 3 (Edge & Air-Gapped)**: SambaNova, Cerebras, Hugging Face Serverless, and local Ollama.
- **Autofix Engine**: Dynamic context trimming, parameter normalization, and exponential jitter retry before cascading.

### 2.4 Auto-Company 24/7 Multi-Squad Governance (S134)
- Continuous agent operations are synchronized via a single shared state file: consensus.md.
- Structured into 3 specialized squads:
  - **Executive Squad**: CEO/Strategist, CFO/Unit Economics, Product Lead.
  - **Engineering Squad**: System Architect, Full-Stack Coder, QA/Test Lead.
  - **Growth Squad**: Growth Hacker, Content Creator, Community Lead.
- Autonomous heartbeat triggers continuous progress evaluation, task dispatch, and milestone commit.

### 2.5 MiniMind-O Multimodal Omni SLM (0.1B)
- Local on-device intelligence utilizes minimind-o Thinker-Talker architecture.
- Thinker processes multimodal input and reasoning; Talker predicts Mimi streaming audio tokens for real-time duplex voice interaction.

- **Zero API Cost Overhead**: Core reasoning runs on free-tier and local models without compromising quality.
